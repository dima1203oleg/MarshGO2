# Канонічний дизайн головної MARSHGO

Еталон, затверджений власником 11 листопада 2026: [зображення](reference/canonical-home-owner-2026-11-11.jpg). Головна має відтворювати композицію: темно-синій фон, верхні елементи, квиток MarshPass, чотири картки дій, популярні напрямки та нижню панель. Елементи мають залишатися робочими.

Зображення є ціллю дизайну; поточна відповідність піксель у піксель потребує перевірки в браузері на однаковому розмірі екрана.
