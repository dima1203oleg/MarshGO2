# Перевірка провайдерів і 12 категорій MARSHGO — 19.10.2026

## Межі перевірки

Перевірено всі 43 джерела з наявного українського каталогу: 38 відкритих URL опитано read-only, 5 пропущено за правилами безпеки або доступу. Також перевірені доступні discovery-кандидати CityBikes, Zelectra та Nextbike. Це охоплює знайдені й налаштовані кандидати репозиторію, але не кожного постачальника у світі. Зовнішні комерційні API потребують окремих ключів, угод і підтвердження покриття.

Повний машинний результат: [14_TRANSPORT_FEED_SMOKE_2026-10-19.json](14_TRANSPORT_FEED_SMOKE_2026-10-19.json). Повторювана команда: `npx tsx tools/transport-feed-smoke.ts` або `npm run acceptance:transport-feeds` (для збереження чистого JSON перенаправляти stdout саме `tsx`, без заголовка npm).

## Джерела та їх стан на час probe

- 43 рядки в українському реєстрі: 38 опитано; **28 healthy, 7 degraded, 3 offline, 5 skipped** (3 незахищені HTTP URL і 2 джерела з ключем). `healthy` тут означає тільки відповідь/структуру фіда.
- Статичний GTFS Львова: 1,071 зупинка, 72 маршрути, 15,716 рейсів, 426,685 stop-times. Два запити до планувальника повернули до 10 ланцюгів кожен, обидва позначені `searchTruncated` і `resultLimitReached`.
- Львівський GTFS-RT на момент probe: 0 VehiclePositions, 0 TripUpdates, 0 Alerts. Івано-Франківський GTFS-RT: 4 позиції, приблизно 3 секунди; Ужгородський: 2 позиції, приблизно 16 секунд; обидва без TripUpdates/Alerts.
- CarpoolWorld має офіційний Quick Search RSS, який документація описує як доступний без developer-акаунта. Запит по Україні був Київ → Львів (між областями, радіус 30 км біля кінців), а не вся країна чи одне місто; endpoint повернув HTML замість RSS/XML. Для контролю звірив і офіційний Jersey City → New York приклад — він також повернув HTML. Українське покриття цим не підтверджене; звіт не називає CarpoolWorld робочим джерелом.
- Деякі Dozor/EasyWay/iCity відповіді мали валідні координати поза очікуваним містом (включно з точкою в Перу). Їх не можна показувати на міській карті без геозонного фільтра для кожної позиції та перевірки прив’язки до маршруту.
- Kyiv official GeoJSON: 127 маршруток-геометрій, 6 metro line features/52 станції, 6 City Express напрямків/34 станції. Це окремо від розкладу або live vehicle positions.
- Відкритий map acceptance: geocoding Львова/Стрия пройшов; OSRM повернув 71.7 км, 1,034 точки форми та 18 маневрів; MapLibre відрендерив карту без помилки. Публічні demo-сервіси не мають гарантій production SLA.

## Реалізовано в цьому проході

- Додано repeatable read-only smoke по всіх відкритих записах українського каталогу та окремо CityBikes/Zelectra/Nextbike.
- У регіональному каталозі не оголошуються партнерські taxi/carsharing/transfer API активними без договору; GBFS не означає доступність оренди; міська геометрія без рейсу не відкриває пошук.
- Київські GeoJSON шари відокремлені за можливостями: геометрія не отримує фальшиві `TRANSIT_STOPS` або timetable capability.
- Ліцензійний parser/міграція більше не виводить комерційний дозвіл із простої доступності фіда; невідомий дозвіл лишається `NULL`.

## Перевірки

- Точкові provider/mode/license тести: 33/33 пройшли.
- `npm run check:production`: 249 пройшли, 0 упали, 1 opt-in тест пропущений; typecheck, lint, Vite production build і bundle budget пройшли (51 JS chunks у межах 350 KB gzip кожен).
- `npm run test:integration`: 30/30 пройшли на окремій loopback `marshgo_e2e` базі, включно з API/DB, бронюванням внутрішньої попутки, GPS navigation, realtime між інстансами, restart і Redis rate limit. У цьому harness GTFS навмисно вимкнено (`MOBILITY_ROUTING_FEEDS_DISABLED=true`), тому його mode matrix закономірно повернула лише внутрішній carpool як маршрутний результат.
- `npm run acceptance:live-providers`: пройшли одноразові geocoding, OSRM і MapLibre checks.
- `git diff --check`: пройшов. Production deployment не виконувався.

## Що блокує повне підключення

Потрібні підтверджені власники/ліцензії й постійний health/freshness контроль фідів; коректні геофільтри для міських JSON позицій; партнерські ключі/угоди для каршерингу, таксі, мікромобільності та квитків; підтвердження прав і affiliate ID для Kiwitaxi; офіційні quotes/availability/booking для комерційних трансферів; а також необрізаний планувальник із приймальною матрицею маршрутів. Без цих умов не можна чесно оголосити всі 12 категорій працюючими провайдерами або production-ready.

## Повторний read-only probe — 19.10.2026, 12:59 UTC

Повторно опитано український каталог із 43 записів: 38 відкритих URL, п’ять пропущено з зафіксованих причин (незахищений HTTP або потрібні облікові дані). Зараз: **32 healthy, 4 degraded, 2 offline, 5 skipped**. Зміна від попереднього probe показує, чому health є часовим зрізом, а не постійною гарантією. Повний результат — [17_TRANSPORT_FEED_RECHECK_2026-10-19.json](17_TRANSPORT_FEED_RECHECK_2026-10-19.json).

Свіжий Львівський static GTFS містить 1,071 зупинку, 72 маршрути, 15,716 рейсів і Europe/Kyiv timezone. Обидва контрольні запити — центр → головний вокзал та Малий Голоско → Сихів — повернули десять результатів, але обидва мали `searchTruncated=true` і `resultLimitReached=true`. У вибірці є багатосегментні пересадки, проте це не доводить глобально оптимальний або повний набір маршрутів; UI має залишати частковий статус видимим.

Додаткові findings:

- Івано-Франківськ/Ужгород не є еквівалентом підтримки кожного міста: конкретні транспортні позиції мусять збігатися з provider + route/trip + direction і свіжим GTFS.
- Zelectra відповіла на GBFS discovery, але розподіл координат цього probe охоплював Ліму та Україну, тому фід деградований і не придатний як український міський live-інвентар.
- `nextbike_lv` показав станції в Латвії, не Україні; `nextbike_vin` повернув 404. CityBikes каталог містив 815 мереж і нуль українських.
- GTFS Inbus і Чорноморська мали дані, але не мали активної служби в наступні сім днів; не можна подавати їх як актуальні розклади.
- Рівне й Трускавець GTFS-RT відповідали, але повертали нуль позицій/оновлень/сповіщень. Це не live fleet.
- Відкриті фіди в цьому probe перевірялись лише на доступність/структуру/базові межі та розклад; комерційні права, SLA, бронювання та фактична якість кожної лінії не підтверджені.
